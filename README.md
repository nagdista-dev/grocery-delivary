# Grocery Delivery

A full-stack grocery delivery application built with the MERN stack — browse products, manage your cart, and place orders.

## Tech Stack

### Frontend
- **React 19** with Vite
- **TypeScript**
- **Tailwind CSS** for styling
- **Leaflet** for map integration

### Backend
- **Node.js** with **Express**
- **MongoDB** with **Mongoose**

## Getting Started

### Prerequisites
- Node.js v18+
- MongoDB instance

### Installation

```bash
git clone https://github.com/nagdista-dev/grocery-delivary.git
cd grocery-delivary
cd client && npm install
cd ../server && npm install
```

### Run

```bash
# From the client directory
npm run dev

# From the server directory
node server.js
```

## Features

- Product browsing and search
- Shopping cart management
- Order placement with map integration
- User authentication
- Responsive design
