A full-stack grocery delivery application built with the MERN stack — browse products, manage your cart, and place orders with map integration.

## Features

- Product browsing and search
- Shopping cart management
- Order placement with map integration (Leaflet)
- User authentication
- Responsive design

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 19, TypeScript, Tailwind CSS, Leaflet |
| Backend | Node.js, Express |
| Database | MongoDB with Mongoose |

## Getting Started

### Prerequisites

- Node.js v18+
- MongoDB instance

### Installation

```bash
git clone https://github.com/nagdista-dev/grocery-delivary.git
cd grocery-delivary
cd client && npm install
cd ../server && npm install
```

### Run

```bash
# From the client directory
npm run dev

# From the server directory
node server.js
```
